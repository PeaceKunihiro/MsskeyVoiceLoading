# Misskey Reader v0.2

`https://misskey.niri.la/` のタイムラインに新しく表示されたノート本文を、ローカルのVOICEVOXで読み上げるChromium拡張です。Misskey API、Cookie、ログイン情報は使用しません。

## 必要環境

- Windows 11
- Google Chrome、Microsoft EdgeなどのChromium互換ブラウザ
- [VOICEVOX](https://voicevox.hiroshiba.jp/)

追加プラグイン、ブリッジアプリ、開発環境は必要ありません。

## インストールと設定

1. VOICEVOXを通常どおり起動します。
2. Chromeは `chrome://extensions/`、Edgeは `edge://extensions/` を開きます。
3. 「デベロッパー モード」を有効にし、「パッケージ化されていない拡張機能を読み込む」でこのフォルダーを選びます。
4. Misskey Readerの設定画面を開きます。
5. ENGINE URLが `http://127.0.0.1:50021` であることを確認し、「話者一覧を取得」を押します。
6. 話者とスタイルを選び、設定を保存して「テスト読み上げ」を押します。
7. Misskeyを再読み込みします。初期設定では、読み込み時点の最新5件を古い順に読み、その後は新着ノートを監視します。

## 主な機能

- VOICEVOX ENGINEでの音声生成と順次再生
- ツールバーアイコンによる即時ON/OFF
- 実投稿日時に基づく初期ノート選択と新着判定
- 投稿時刻順の読み上げキュー、最大待機件数、投稿の有効時間
- URL除去、カスタム絵文字除外、最大読み上げ文字数
- CW、引用元、通常Renote、添付のみの投稿の除外
- バックグラウンドタブでのDOM監視
- 話者・スタイル、話速、音高、抑揚、音量の設定
- MisskeyユーザーIDごとのカスタム話者設定
- ノートごとのランダム声音、声音別音量、左右ステレオバランス

設定項目と内部動作の変更履歴は [UPDATELOG.md](UPDATELOG.md) を参照してください。

## 読み上げ処理

VOICEVOX ENGINEの `/audio_query` と `/synthesis` APIでWAV音声を生成し、Manifest V3のoffscreen documentで再生します。音声は投稿時刻順に1件ずつ生成・再生するため重なりません。

初期ノート、新着ノートともにノート自身の `time` 要素から実投稿日時を取得します。日時不明や設定時間を超えたノートは読み上げず、待機中にも再生直前に鮮度を再確認します。

ツールバーアイコンをクリックすると読み上げのON/OFFを切り替えられます。OFF時は再生中音声と待機キューを停止し、OFF中のノートを後から読みません。

「カスタム読み上げ」では、`@user` または `@user@host` とVOICEVOXの話者・スタイルを対応付けられます。登録のないユーザーや、削除・無効になったstyle IDにはデフォルト話者を使用します。

「ランダム声音」では複数のstyleを対象に選び、ノートごとにランダムな声音を使用できます。各styleにはVOICEVOXへ渡す音量倍率と、再生時の左右ステレオバランス（-1から+1）を設定できます。ランダムOFF時は既存のカスタム話者／デフォルト話者を使用します。

## 動作と制限

- DOMの `data-scroll-anchor`、`article`、表示状態を中心に判定し、右カラム、折り畳まれたCW、引用先、添付、カスタム絵文字を除外します。
- 本文がない画像・ファイルだけのノートと、通常Renoteは読みません。
- 引用Renoteは外側に入力されたコメントのみを候補にします。
- MisskeyのDOM構造変更により本文を検出できなくなる可能性があります。開発者ツールの `[MisskeyReader]` ログで判定状況を確認できます。

## 別PCのVOICEVOX

Tailscale等で到達可能な別PCのENGINE URLも設定できます。初回保存時に、その接続先だけに対するChromeのアクセス権限確認が表示されます。URLには `http` または `https` のみ使用できます。VOICEVOX ENGINEを不特定多数へ公開しないでください。

## プライバシー

ノート本文は設定したVOICEVOX ENGINEにだけ送信します。初期設定では、このPCの `127.0.0.1:50021` だけを使用します。
