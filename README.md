# Misskey Reader v0.2

Misskeyのタイムラインに表示されたノート本文を、ローカルまたは指定したVOICEVOX ENGINEで読み上げるChromium拡張です。

Misskey API、Cookie、ログイン情報は使用せず、許可したMisskeyインスタンスのタイムラインDOMからノート本文・投稿者ID・投稿時刻を取得します。

## 必要環境

- Windows 11
- Google Chrome、Microsoft EdgeなどのChromium互換ブラウザ（Chrome 109以降相当）
- [VOICEVOX](https://voicevox.hiroshiba.jp/)

追加プラグイン、ブリッジアプリ、Visual Studio、Python、Node.js等の開発環境は必要ありません。

## インストール

1. VOICEVOXを通常どおり起動します。
2. Chromeは `chrome://extensions/`、Edgeは `edge://extensions/` を開きます。
3. 「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダーを選びます。
5. Misskey Readerの設定画面を開きます。
6. 読み上げ対象のMisskeyインスタンスを登録し、アクセス権限を許可します。
7. VOICEVOX ENGINE URLが `http://127.0.0.1:50021` であることを確認し、「話者一覧を取得」を押します。
8. 話者・スタイルや各種読み上げ設定を保存し、「テスト読み上げ」で動作を確認します。
9. 対象Misskeyタブを再読み込みします。

初期設定では、ページ読み込み時点で対象となる最新5件を古い順に読み、その後は新着ノートを監視します。

## 主な機能

- VOICEVOX ENGINEの `/audio_query` / `/synthesis` による音声生成
- Manifest V3 offscreen document + Web Audio APIによる音声再生
- ツールバーアイコンによる読み上げON/OFF
- ロード済ノートの初回読み上げ件数設定
- 実投稿日時に基づく新着・遅延描画判定
- 投稿の有効時間設定と、キュー投入時／再生直前の鮮度判定
- 待機キュー最大件数と、超過時の古いノート破棄
- 最大読み上げ文字数
- HTTP/HTTPS URLの除去
- カスタム絵文字の除外
- CW、通常Renote、画像・ファイルのみの投稿などの除外
- MisskeyユーザーIDごとのカスタム話者設定
- ノートごとのランダム声音
- 声音ごとの音量倍率
- 声音ごとの左右ステレオバランス
- 1～4件の同時VOICEVOX生成・再生
- 複数Misskeyインスタンスの登録
- Misskeyインスタンスごとの任意ホスト権限
- 別PC上のVOICEVOX ENGINEへの接続
- `[MisskeyReader]` デバッグログ

設定項目と内部動作の変更履歴は [UPDATELOG.md](UPDATELOG.md) を参照してください。

## 読み上げ処理

ノート候補はDOM更新ごとに即時読み上げせず、短時間集約してから処理します。

主な流れは次のとおりです。

```text
MisskeyタイムラインDOM更新
↓
候補ノートを短時間集約
↓
Note IDで重複排除
↓
投稿日時・有効時間・viewportを確認
↓
読み上げ対象をVOICEVOXキューへ投入
↓
設定した同時読み上げ数（1～4）まで並行処理
↓
VOICEVOXでWAV生成
↓
声音ごとのステレオ設定を適用して再生
```

初期ノート、新着ノートともにノート自身の `time` 要素から投稿日時を取得します。`datetime`、`title`、親要素の `title`、`data-timestamp`、`data-time`、`aria-label` などを解析し、日時を取得できない場合は現在時刻へ置き換えません。

有効時間が設定されている場合、日時不明または期限切れのノートは読み上げません。待機中に古くなったノートも、再生直前の再判定で破棄します。

Note IDと投稿時刻を併用して重複・遅延描画を判定します。同一時刻の別ノートはNote IDが異なれば別ノートとして扱います。

## 読み上げON/OFF

ツールバーアイコンをクリックすると読み上げのON/OFFを切り替えられます。

OFF時は再生中の音声を停止し、待機キューを破棄します。OFF中に検出したノートは後から遡って読み上げません。

## カスタム読み上げ

MisskeyユーザーIDとVOICEVOXの話者・スタイルを対応付けられます。

```text
@user
@user@host
```

登録のないユーザーや、現在のVOICEVOXで利用できないstyle IDにはデフォルト話者を使用します。

## ランダム声音・声音別設定

「ランダム声音」を有効にすると、選択した複数のVOICEVOX style IDからノートごとにランダムで声音を選びます。

各styleには個別に次の設定を保存できます。

- 音量倍率：`0.0` ～ `2.0`
- ステレオバランス：`-1.0`（左）～ `+1.0`（右）

ステレオ処理はVOICEVOX側ではなく、offscreen document内のWeb Audio API `StereoPannerNode` で適用します。

ランダム声音がOFFの場合は、カスタム話者設定またはデフォルト話者を使用します。

ランダム声音が有効で同時読み上げ数が1以上の場合、複数のVOICEVOX声音モデルが読み込まれてVRAM消費量が増大する可能性があります。設定画面の警告を確認し、GPUの空き容量に注意してください。

## 同時読み上げ

「同時読み上げ数」は1～4件から選択できます。初期値は1です。

- `1`：従来どおり1件ずつ読み上げ
- `2`～`4`：指定件数までVOICEVOX生成・再生を並行実行

並行再生時も、各音声の声音別音量とステレオ設定は個別に維持されます。

Global TLなど流速の高いタイムラインでは、待機キュー最大件数や投稿の有効時間と組み合わせ、古いノートを捨てながら最新側を読む運用を想定しています。

## 読み上げ対象Misskeyインスタンス

読み上げ対象のMisskeyインスタンスURLを複数登録できます。

```text
https://misskey.niri.la
https://misskey.io
```

URLはorigin単位で保存されます。登録時には拡張独自の確認ダイアログで、対象URL・読み取る情報・利用目的を表示した後、Chromeのホスト権限要求を行います。

許可されたインスタンスだけにcontent scriptを動的登録します。インスタンス削除時には対応する権限と読み上げ対象も解除します。

### Misskey側から読み取る情報

- タイムラインに表示されたノート本文
- 投稿者ID
- 投稿時刻

これらは読み上げ判定とVOICEVOX音声生成のために使用します。Misskey APIトークンやログインCookieは使用しません。

## DOM監視とバックグラウンドタブ

`MutationObserver`でMisskeyのタイムラインDOMを監視します。`requestAnimationFrame`には依存しないため、content script自体はバックグラウンドタブでもDOM更新を処理できる構成です。

ただし、Misskey本体が非アクティブタブで新着ノートのDOM描画を停止・遅延する場合、拡張側には新着DOMが届かないため、その間は読み上げできません。再びタブが前面になった際も、背景中に蓄積した古い候補を大量に遡って読まない方針です。

そのため、確実なリアルタイム読み上げが必要な場合は、対象Misskeyタブを前面表示した状態での利用を推奨します。

## 動作と制限

- MisskeyのDOM構造に依存するため、Misskey本体や各フォークのDOM変更によって検出できなくなる可能性があります。
- 中央タイムライン、Note ID、投稿時刻、viewportとの交差などを基準に読み上げ対象を判定します。
- 画面外、期限切れ、上限超過、遅延描画と判断した候補は読み上げず既読扱いにする場合があります。
- 通常Renoteは読み上げません。引用Renoteは外側のコメントのみを読み上げ候補とします。
- 本文がない画像・ファイルのみのノートは読み上げません。
- 折り畳まれたCW本文や引用先本文は読み上げ対象外です。
- 高速なGlobal TLなどでは、すべてのノートを読み上げることより最新ノートへの追従を優先するため、一部ノートを意図的に破棄する場合があります。
- 判定状況は開発者ツールの `[MisskeyReader]` ログで確認できます。

## 別PCのVOICEVOX

Tailscale等で到達可能な別PCのVOICEVOX ENGINE URLも設定できます。

ローカル既定の `http://127.0.0.1:50021` / `http://localhost:50021` 以外を指定した場合は、その接続先に対するChromeの任意ホスト権限が必要です。URLには `http` または `https` を使用できます。

VOICEVOX ENGINEをLANやTailscale外の不特定多数へ公開しないでください。

## プライバシー

ノート本文は、ユーザーが設定したVOICEVOX ENGINEへ音声生成のため送信されます。初期設定では、このPCの `127.0.0.1:50021` を使用します。

Misskey Reader自身が独自の外部サーバーへノート本文を送信する処理はありません。
